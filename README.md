# Etch-a-Sketch

A browser-based Etch-a-Sketch project built as part of **The Odin Project**.

## What I Learned

- DOM manipulation
- Creating elements dynamically with JavaScript
- Event listeners and mouse events
- Working with CSS Grid
- Generating dynamic grid layouts
- Handling user input
- Functions and loops
- Basic JavaScript problem-solving
- Connecting JavaScript with CSS to create interactive UI

Built to practice **JavaScript fundamentals, DOM manipulation, and interactive web development**.
